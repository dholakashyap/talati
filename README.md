# Talati Exam Prep: content feed

Public content that the Talati Exam Prep app (`com.dhola.talati`) downloads, so it can
be updated without a new app release. This is not an official GPSSB or government source.

| Path | What |
|---|---|
| `ca/index.json` | The last 60 days that have current affairs |
| `ca/<yyyy-mm-dd>.json` | That day's items: a short English and Gujarati note, one question, and links to the original reports |
| `ca/seen.json` | Links already processed |

Current affairs are written for exam revision from official releases (PIB) and news
reports; each item links to its sources. Files here are updated automatically.
